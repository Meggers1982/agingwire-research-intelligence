# Data model

## EvidenceItem
Key fields: source_id, source_type, title, URL, date, organization/authors, topics, geographies, methodology, sample size, primary-data flag, peer-reviewed flag, commercial-interest flag, evidence grade, claim-level provenance.

## CoverageItem
Publisher, audience type, title, URL, date, topic, framing, geography, evidence links found.

## StoryOpportunity
Evidence IDs, novelty, impact, localization, consumer utility, B2B relevance, visualization potential, reporting burden, caveats, reporting questions, target publishers and prior-coverage matches.
