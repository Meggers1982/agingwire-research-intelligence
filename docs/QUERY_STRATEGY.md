# Query strategy

The companion layer fixes exact-phrase blind spots without touching the existing PubMed repo.

Each topic has synonym bundles, source-specific variants and optional controlled vocabulary. Example: caregiving includes caregiver, family caregiver, informal care, unpaid care, carer and caregiver burden.

Government datasets should be queried by tables/variables rather than vague keywords. RSS/report sources can be classified after ingestion. Media coverage is used for saturation and editorial-gap analysis, not evidence grading.

Every candidate should be tested for localization potential at state, county, metro/place, facility/provider, rural/urban and demographic subgroup levels.
